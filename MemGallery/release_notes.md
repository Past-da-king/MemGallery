# MemGallery v0.2.0 - The Premium Update 🚀

This release introduces the **Timeline Pulse Widget**, a complete visual overhaul, and real-time synchronization features designed to make your memories feel alive on your home screen.

## ✨ New Features
- **Timeline Pulse Widget**: A stunning new home screen widget that pulses your memories in a beautiful, vertical timeline.
- **Ultra-Premium Visuals**:
    - **"Jewel" Thumbnails**: Images now feature high-quality scaling and themed glow rings.
    - **Date Pills**: Dates are elegantly encased in semi-transparent, themed chips for a modern tech aesthetic.
    - **Dynamic Spacing**: Refined typography and hierarchy (Title > Summary > Date).
- **Real-Time Sync**: Changes to app theme colors or memory data reflect instantly on the widget—no manual refresh required.

## 🛠️ Improvements & Fixes
- **Memory Optimized**: Aggressive bitmap downscaling and item capping to ensure zero `RemoteViews` crashes.
- **Intelligent Hierarchy**: Better text clamping and spacing for various widget sizes.
- **Themed Accents**: The widget now fully respects your custom app colors.
