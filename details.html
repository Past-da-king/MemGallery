Smart Task Management

MemGallery doesn't just save notes; it helps you stay on top of things by suggesting tasks from your memories.

The Lifecycle of a Task

You save a memory (text, image, or voice)
The AI scans it for important dates or things to do
You review the suggested task in a simple popup
Once approved, it's saved securely on your phone
You can even export tasks to your Google Calendar or Tasks
How we handle your tasks 

fun createCalendarEventIntent(action: ActionDto): Intent {
    return Intent(Intent.ACTION_INSERT).apply {
        data = CalendarContract.Events.CONTENT_URI
        putExtra(CalendarContract.Events.TITLE, action.description)
        if (action.date != null) {
            val startTime = parseDateTime(action.date, action.time)
            putExtra(CalendarContract.EXTRA_EVENT_BEGIN_TIME, startTime)
            putExtra(CalendarContract.EXTRA_EVENT_END_TIME, startTime + 3600000)
        }
    }
}

Security & Privacy

MemGallery is built to keep your data private by design.

Locked in Hardware

We don't just "save" your API keys. We lock them in your phone's secure hardware enclave.

Security Implementation 

private val masterKeyAlias = MasterKeys.getOrCreate(MasterKeys.AES256_GCM_SPEC)
private val encryptedPrefs = EncryptedSharedPreferences.create(
    "secure_settings",
    masterKeyAlias,
    context,
    EncryptedSharedPreferences.PrefKeyEncryptionScheme.AES256_SIV,
    EncryptedSharedPreferences.PrefValueEncryptionScheme.AES256_GCM
)
A master key is generated inside your phone's secure hardware
Your settings and API keys are double-encrypted
Access is only granted when the app signature matches exactly
Your private keys never leave the secure hardware area
