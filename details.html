The Task Intelligence Pipeline

Unlike basic todo apps, MemGallery uses a multi-stage user-approval pipeline to prevent database pollution.

The Lifecycle of a Task

Capture triggering -> MemoryEntity created in Room DB
AI Inference -> Maverick-128e detects Intent and creates ActionDto
Review Sheet -> User verifies, edits, or deletes the proposed Task
Persistence -> Approved Task committed to TaskEntity v16
Ecosystem Export -> Native ACTION_INSERT Intent pushes to Google Tasks
ActionHandler.kt Implementation 

fun createCalendarEventIntent(action: ActionDto): Intent {
    return Intent(Intent.ACTION_INSERT).apply {
        data = CalendarContract.Events.CONTENT_URI
        putExtra(CalendarContract.Events.TITLE, action.description)
        if (action.date != null) {
            val startTime = parseDateTime(action.date, action.time)
            putExtra(CalendarContract.EXTRA_EVENT_BEGIN_TIME, startTime)
            putExtra(CalendarContract.EXTRA_EVENT_END_TIME, startTime + 3600000)
        }
    }
}

Dual-Engine Inference

Why do we use two providers? Because speed and depth are mutually exclusive at the edge.

Gemini 1.5 Pro

Reserved for "Global Semantic Retrieval." When the AI tool queryDatabase is called, Gemini scans your entire memory history with its 128k context window to find non-obvious links.

Llama-4 Maverick

Reserved for "High-Fidelity Analysis." Powered by Groq LPUs, it processes image/audio captures in <50ms, achieving real-time tagging accuracy that outperforms cloud models.

EncryptedSharedPreferences Protocol

We don't just "save" keys. We lock them in hardware.

SettingsRepository.kt Sec Ops 

private val masterKeyAlias = MasterKeys.getOrCreate(MasterKeys.AES256_GCM_SPEC)
private val encryptedPrefs = EncryptedSharedPreferences.create(
    "secure_settings",
    masterKeyAlias,
    context,
    EncryptedSharedPreferences.PrefKeyEncryptionScheme.AES256_SIV,
    EncryptedSharedPreferences.PrefValueEncryptionScheme.AES256_GCM
)
MasterKey generated in TEE (Trusted Execution Environment)
AES256_SIV scheme encrypts the Preference Key itself
AES256_GCM scheme encrypts the API Key value
Keys only valid when the TEE-bound app signature matches

AccessibilityService

How the Edge Gesture works. MemGallery requests BIND_ACCESSIBILITY_SERVICE to draw a floating window over all other apps. It samples screen coordinates to detect swipe events without interrupting your background apps.

FileObserver

The Screenshot Observer monitors /DCIM/Screenshots. When a MOVED_TO or CREATE bit is flipped in the Linux kernel, MemGallery wakes the AI engine to index the new image instantly.
